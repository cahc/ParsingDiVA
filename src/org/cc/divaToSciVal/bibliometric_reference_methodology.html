Documentation of Subject-Matched Swedish Reference Indicators

Formal description of the construction of publication-specific reference sets, observed and expected bibliometric indicators, aggregation rules, fallback procedures, and recommended presentation of citation-impact classes.

Purpose Reference construction Observed indicators Expected indicators Aggregation Citation-impact classes Presentation example Implementation Interpretation

1. Purpose and analytical unit

The analytical unit is the individual focal publication. Each focal publication is assigned both an observed indicator value and a publication-specific expected value derived from a Swedish, external, subject-related reference set.

Core principle. The reference value for a group of focal publications is the arithmetic mean of the publication-specific expected values. Reference publications are not pooled into one common set before aggregation.

The method does not reconstruct global citation percentiles. The citation-percentile variable is taken as an already normalized publication-level property. The present method instead asks how the focal publications compare descriptively with subject-related publications from the Swedish research system outside the focal organizational unit.

2. Construction of publication-specific reference sets

2.1 External Swedish benchmark population

The benchmark universe consists of Swedish publications that are not associated with the focal organizational unit. Publications belonging to the focal organization, accepted focal EIDs, and excluded document types (Retracted, Abstract Report, Erratum, Editorial, Conference Review) are removed before reference sets are constructed. EIDs are normalized and deduplicated. This prevents the evaluated organization from contributing to its own benchmark.

2.2 Subject similarity

For each focal publication i, subject-related benchmark publications are identified using two complementary classification systems:

  1. Exact ASJC partition cell. Publications are included when their journal is classified in exactly the same complete combination of ASJC subject codes as the focal publication.
  2. Citation-based topic cluster. Publications are included when they belong to the same algorithmically constructed citation cluster as the focal publication.

The final reference set is the inclusive union of these two sets:

Ri = Gi ∩ (RASJC,i ∪ RTC,i)

A publication satisfying both subject criteria occurs only once. Gi is the focal publication's document-type group: journal (Article in Press, Letter, Data Paper, Short Survey, Note, Article, Review), conference (Conference Paper), or book/chapter (Book, Chapter, Book Chapter). Grouping uses document type, independently of source type. Unknown and missing document types remain eligible and receive generic Swedish expectations directly.

The operational meaning of subject-related is therefore: a Swedish, non-focal-organization publication in the same document group that shares either the focal publication's exact ASJC partition cell or its citation-based topic cluster.

2.3 Minimum reference-set sizes and fallback

Very small reference sets generate unstable publication-specific proportions. Minimum sizes are therefore imposed before a subject-specific expectation is accepted:

Indicator familyMinimum subject reference sizeFallback
Top 10% / Top 50%25Whole document group (minimum 25), then generic external Swedish benchmark
International collaboration20Whole group in year ±1 (minimum 20), then generic Swedish year window (minimum 20), then generic Swedish benchmark across all years

The international-collaboration indicator uses a time-restricted reference set because international collaboration is not itself normalized by publication year and may change systematically over time.

3. Observed publication-level indicators

Let Pi denote the citation-percentile value of focal publication i. The observed binary indicators are:

Y10,i = 1 if Pi ≤ 10, otherwise 0
Y50,i = 1 if Pi ≤ 50, otherwise 0
YINT,i = 1 if publication i involves at least two countries, otherwise 0

The use of “≤” is important. Because citation counts are discrete and ties can occur, the labels “Top 10%” and “Top 50%” should be understood as classifications defined by the supplied percentile variable, not as a claim that exactly 10.0% or 50.0% of every underlying population must fall into those classes.

4. Expected publication-level indicator values

4.1 Citation impact

For a focal publication i with an accepted subject reference set Ri, the expected Top-10 and Top-50 values are the corresponding proportions among the reference publications:

p10,i = (number of publications j in Ri with Pj ≤ 10) / |Ri|
p50,i = (number of publications j in Ri with Pj ≤ 50) / |Ri|

If |Ri| < 25, use the entire external document group when it contains at least 25 publications; otherwise use the generic external Swedish benchmark.

4.2 International collaboration

For international collaboration, the subject reference set is first restricted to publications within a centered three-year window around the focal publication:

RINT,i = { j in Ri : |yearj - yeari| ≤ 1 }

The expected international-collaboration value is then:

pINT,i = (number of international publications in RINT,i) / |RINT,i|

If |RINT,i| < 20, use the entire external document group in the same year window when it contains at least 20 publications; otherwise use the generic Swedish window when it contains at least 20. If that too is insufficient, use the generic Swedish benchmark across all years. Missing focal years use the all-years fallback directly. Final fallbacks accept any nonempty benchmark, so every eligible focal publication receives an expectation. An entirely empty eligible external benchmark is a run-level error.

5. Aggregation for arbitrary groups of focal publications

For a group of N focal publications, the observed indicator is the mean of the publication-level binary values:

Observed Top 10% = (1/N) Σ Y10,i

The corresponding reference value is the mean of the publication-specific expected values:

Expected Top 10% = (1/N) Σ p10,i

The same aggregation rule is used for Top 50% and international collaboration.

Do not pool all reference publications before calculating the benchmark. Reference-set sizes can differ greatly across focal publications. Pooling would give more weight to focal publications that happen to have larger reference sets. Averaging the publication-specific expected values gives every focal publication equal weight, matching the weighting used for the observed focal indicator.

The result can therefore be presented simply as two directly comparable descriptive values, for example:

Top 10% — focal publications: 15.6%; Swedish subject reference: 17.6%.

6. Citation-impact classes from the Top-10 and Top-50 indicators

Because every publication classified as Top 10% is also classified as Top 50%, the two binary indicators can be decomposed into three mutually exclusive citation-impact classes.

ClassObserved definitionExpected definition
Top 10% Y10,i p10,i
Top 50%, excluding Top 10% Y50,i − Y10,i p50,i − p10,i
Outside Top 50% 1 − Y50,i 1 − p50,i

This decomposition is exact. It does not require citation counts to behave like a continuous variable and does not depend on percentiles having perfectly equal-sized groups. For reporting, the label “Top 50%, excluding Top 10%” is therefore preferable to wording such as “11th–50th percentile”.

The three classes sum to 100% for both the focal publications and the reference values, allowing citation-impact profiles to be compared as complete distributions rather than as two overlapping binary indicators.

7.3 Example narrative

The focal publications have a somewhat lower share of publications in the Top-10 citation class than their subject-matched Swedish reference (15.6% versus 17.6%). The share in the intermediate citation-impact class, Top 50% excluding Top 10%, is almost identical (52.8% versus 53.1%). The difference in the overall citation profile is therefore concentrated primarily at the upper and lower ends: the focal set has fewer Top-10 publications and a correspondingly larger share outside the Top 50% (31.6% versus 29.3%). International collaboration is also lower in the focal set (58.7%) than in the temporally and subject-matched Swedish reference (67.1%).

8. Implementation and output

SwedishReferenceIndicatorCalculator is the single implementation of the reference methodology. It receives the Swedish SciVal records and the accepted focal EIDs in memory, constructs the benchmark indexes once, and returns one immutable ReferenceIndicators value per unique focal EID.

MatchDiVAToSciVal invokes the calculator after matching and shared-target post-processing are complete, then appends the observed values, expected values, reference-set sizes, fallback flags, normalization group, reference scopes, and actual denominator sizes to both its TSV and XLSX rows. Several DiVA PIDs linked to the same EID receive the same EID-level indicator values.

Indicator values are produced only for accepted statuses: EXACT, EXACT_SUSPECT, and TEXT_AUTO_MATCH. Indicator cells remain blank for IGNORED, IDENTIFIER_CONFLICT, AMBIGUOUS, and NO_MATCH. A diagnostic SciVal candidate is never treated as an accepted focal publication.

RunCitationIndicatorPipelineOnAlreadyMaterializedParquetFile is retained only as a compatibility runner for previously materialized match files; it delegates all calculations to the same calculator.

9. Interpretation and reporting guidance

Descriptive, not causal
The expected values describe the performance of subject-related Swedish publications outside the focal organization. They do not establish what the focal organization would have achieved under a causal counterfactual.
Reference values are portfolio-specific
Because every focal publication contributes its own expected value, the aggregate reference automatically reflects the subject composition of the particular focal portfolio being reported.
Equal weighting of focal publications
Each focal publication contributes equally to the observed mean and equally to the expected mean, irrespective of the size of its underlying reference set.
Small-set fallbacks should remain auditable
Fallback flags and reference-set sizes should be retained in the analytical dataset so that coverage and sensitivity can be inspected even when only the simplified focal-versus-reference values are shown to end users.
Recommended citation-impact presentation
For reporting, present the three mutually exclusive classes: Top 10%; Top 50%, excluding Top 10%; and Outside Top 50%. This avoids implying that citation percentile groups must be perfectly continuous or exactly equal in size.
Documentation reflects the implemented methodology: Swedish non-focal-organization benchmark population; subject matching by same document group intersected with the inclusive union of exact ASJC partition and citation-based topic cluster; group and generic Swedish fallbacks; minimum reference sizes of 25 for citation indicators and 20 for international collaboration; and publication-level averaging of expected values.
